# 🎨 UI/UX Pro Max Engine

Comprehensive design intelligence system for crafting world-class, professional web and mobile interfaces.

## 🚀 How to Use (CLI Search)

Use the built-in BM25 search engine to discover design patterns, token palettes, animations, and component recipes:

```bash
# Style & Aesthetic Search
python .agent/skills/ui-ux-pro-max/scripts/search.py "dark fintech minimalist" --domain style

# Color Palette Search
python .agent/skills/ui-ux-pro-max/scripts/search.py "saas finance investment" --domain color

# Chart Guidance
python .agent/skills/ui-ux-pro-max/scripts/search.py "cashflow trends" --domain chart

# Stack-specific Guidelines (e.g. Tailwind, React, Next.js)
python .agent/skills/ui-ux-pro-max/scripts/search.py "dashboard tables" --stack html-tailwind
python .agent/skills/ui-ux-pro-max/scripts/search.py "modal animations" --stack react

# Generate Complete Design System for a Project
python .agent/skills/ui-ux-pro-max/scripts/search.py "fintech" --design-system -p "FinalZap"
```

## 📊 Available Domains
- `style`: 50 distinct aesthetic categories, keywords, colors, complexity, and performance notes.
- `color`: 21 product-type palettes with primary, secondary, CTA, background, text, and border hexes.
- `chart`: Recommendations by data type, libraries, color guidance, and accessibility notes.
- `landing`: Section ordering, conversion optimization, CTA placements.
- `product`: Product-type mapping to primary and secondary styles.
- `ux`: Best practices, Do's & Don'ts, code examples, severity ratings.
- `typography`: Font pairings (Google Fonts + Tailwind config) matched by mood.
- `icons`: Icon recommendations by category and usage.

## 💻 Supported Stacks
`html-tailwind`, `react`, `nextjs`, `vue`, `nuxtjs`, `nuxt-ui`, `svelte`, `swiftui`, `react-native`, `flutter`, `shadcn`, `jetpack-compose`.
